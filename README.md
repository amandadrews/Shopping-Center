Projeto desenvolvido em Java para a disciplina de Laboratório I (2026/1), com o objetivo de desenvolver um sistema para o gerenciamento de lojas em um Shopping Center, aplicando na prática os principais conceitos de Programação Orientada a Objetos (POO), como: Encapsulamento
herança, polimorfismo, interação entre classes, rganização e reutilização de código.

O sistema do Shopping permite o cadastro, gerenciamento e exclusão de lojas, assim como o controle de informações relacionadas aos seus funcionários.
Cada uma das loja pode possuir características específicas de acordo com sua categoria.

Todas as funcionalidades do sistema são acessadas por meio de um menu numérico, com submenus específicos para cada escolha feita pelo usuário no terminal. 

O sistema possibilita cadastro de funcionários, lojas, e produtos para as lojas associ0-os as duas respectivas lojas.
